# 정보처리기사
## 통합 구현
### 56. 통합 구현
#### [1] 통햡 구현
- **통합 구현** ; 사용자의 요구사항에 맞춰 **송·수신 모듈과 중계 모듈 간의 연계를 구현하는 것**  

<br>

- 통합 구현의 구성 요소
  - 송신 시스템과 모듈
  - 수신 시스템과 모듈
  - 중계 시스템
  - 연계 데이터
  - 네트워크

<br>

#### [2] 연계 요구사항 분석
- **연계 요구사항 분석** ; 통합 구현을 위해 사용자 요구사항을 분석하여 **연계 데이터를 식별 및 표준화하여 연계 데이터를 정의하는 것**

<br>

#### [3] 연계 데이터 식별 및 표준화의 절차
- (1) 연계 범위 및 항목 정의

- (2) 연계 코드 변환 및 매핑

- (3) 연계 데이터 식별자와 변경 구분 추가

- (4) 연계 데이터 표현 방법 정의

- (5) 연계 정의서 및 명세서 작성

<br>
<br>

### 57. 연계 메커니즘
#### [1] 연계 메커니즘
- 연계 메커니즘의 연계 방식

|연계 방식|설명|
|:---:|:---:|
|직접 연계 방식|중간 매개체 없이 송·수신 시스템이 직접 연계<br>종류 : DB Link, API/Open API, DB Connection, JDBC 등|
|간접 연계 방식|송·수신 시스템 사이에 중간 매개체를 두어 연계<br>종류 : 연계 솔루션, ESB, 소켓(Socket), 웹 서비스(Web Service) 등|

<br>

#### [2] 연계 메커니즘의 구성

|연계 메커니즘|설명|
|:---:|:---:|
|연계 데이터 생성 및 추출|응용 시스템에서 연계 데이터를 생성 및 추출|
|코드 매핑 및 데이터 변환|송신 시스템에서 사용하는 코드를 수신 시스템에서 사용하는 코드로 매핑 및 변환|
|인터페이스 테이블 또는 파일 생성|연계 데이터를 인터페이스 테이블이나 파일 형식으로 생성|
|로그(Log) 기록|송·수신 시스템에서 수행되는 모든 과정에 대한 결과 및 오류를 로그 테이블이나 파일에 기록|
|연계 서버 또는 송·수신 어댑터|연계 서버 : 송·수신과 관련된 모든 처리 수행<br>송신 어댑터 : 인터페이스 테이블 또는 파일의 데이터를 변환 및 송신<br>수신 어댑터 : 수신 데이터를 인터페이스 테이블이나 파일로 생성|
|전송|생성된 연계 데이터를 네트워크 환경에 맞는 데이터로 변환 및 수신 시스템으로 전송|
|운영 DB에 연계 데이터 반영|인터페이스 테이블 또는 파일 구조의 데이터를 변환하여 수신 시스템의 운영 DB에 반영|

<br>
<br>

### 58. 연계 장애 및 오류처리 구현
#### [1] 연계 매커니즘 구간별 장애 및 오류 모니터링 현황
- 구간별 주요 오류 발생 시점

|구간|오류 발생 시점|
|:---:|:---:|
|송신 시스템|데이터 생성 및 추출 시<br>코드 매핑 및 데이터 변환 시<br>인터페이스 테이블 또는 파일 등록 시|
|수신 시스템|연계 데이터 로드(Load) 시<br>코드 매핑 및 데이터 변환 시<br>운영 DB에 반영 시|
|연계 서버|연계 데이터 로드(Load) 및 전송 형식으로 변환 시<br>연계 데이터 송·수신 시<br>수신 시스템의 데이터 형식으로 변환 및 로드(Load) 시|

<br>
<br>

### 59. 연계 데이터 보안 적용
#### [1] 전송 구간 보안
- **전송 구간 보안** : **전송되는 데이터나 패킷(Packet)을 쉽게 가로챌 수 없도록 암호화 기능이 포함된 보안 프로토콜을 적용하는 것**

<br>

#### [2] 데이터 보안
- **데이터 보안** : **송신 시스템에서 연계 데이터를 추출할 떄와 수신 시스템에서 데이터를 운영 DB에 반영할 때 데이터를 암·복호화 하는 것**

<br>
<br>

### 60. XML(eXtensible Markup Language)
#### [1] XML
- **XML** : **특수한 목적을 갖는 마크업 언어를 만드는 데 사용되는 다목적 마크업 언어**

<br>

#### [2] SOAP(Simple Object Access Protocol)
- **SOAP** : **네트워크 상에서 HTTP/HTTPS, SMTP 등을 이용하여 XML을 교환하기 위한 통신 규약**

<br>

#### [3] WSDL(Web Services Description Language)
- **WSDL** : **웹 서비스와 관련된 서식이나 프로토콜 등을 표준적인 방법으로 기술하고 게시하기 위한 언어**

<br>
<br>

### 61. 연계 테스트
#### [1] 연계 테스트의 개요
- **연계 테스트** : **연계 시스템과 연계 시스템의 구성 요소가 정상적으로 동작하는지 확인하는 활동**

<br>

- 연계 테스트 진행 순서
  - 연계 테스트 케이스 작성
  - 연계 테스트 환경 구축
  - 연계 테스트 수행
  - 연계 테스트 수행 결과 검증
