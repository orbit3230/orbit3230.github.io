# 정보처리기사
## 소프트웨어 개발 보안 구축
### 109. Secure SDLC
#### [1] Secure SDLC
- **Secure SDLC** : **SDLC(소프트웨어 개발 생명주기)에 보안 강화를 위한 프로세스를 포함한 것**

- Secure SDLC의 대표적인 방법론

|방법론|설명|
|:---:|:---:|
|CLASP|SDLC의 초기 단계에서 보안을 강화하는 방법론|
|SDL|마이크로소프트에서 제시한 SDLC 보안 강화 방법론|
|Seven Touchpoints|소프트웨어 보안의 모범사례를 SDLC에 적용한 방법론|

<br>

#### [2] 소프트웨어 개발 보안 요소

|보안 요소|설명|
|:---:|:---:|
|기밀성(Confidentiality)|시스템 내 정보와 자원은 인가된 사용자에게만 접근이 허용됨|
|무결성(Integrity)|시스템 내 정보는 오직 인가된 사용자만 수정할 수 있음|
|가용성(Availability)|시스템 내 정보와 자원을 언제라도 사용할 수 있음|
|인증(Authentication)|사용자가 합법적인 사용자인지를 확인|
|부인 방지(NonRepudiation)|송·수신 사실을 부인할 수 없도록 송·수신 증거를 제공|

<br>

#### [3] 시큐어 코딩(Secure Coding)
- **시큐어 코딩** : **보안 요소들을 고려하며 코딩하는 것**

<br>
<br>

### 110. 입력 데이터 검증 및 표현
#### [1] 입력 데이터 검증 및 표현
- 입력 데이터 검증 및 표현의 보안 약점

|보안 약점|설명|
|:---:|:---:|
|SQL 삽입(SQL Injection)|웹 응용 프로그램에 SQL을 삽입하여 DB 유출 및 변조|
|경로 조작 및 자원 삽입|데이터 입출력 경로를 조작하여 서버 자원을 수정·삭제|
|크로스사이트 스크립팅(XSS)|웹 페이지에 악의적인 스크립트를 삽입하여 정보 탈취 및 비정상적인 기능 수행 유발|
|운영체제 명령어 삽입|외부 입력값을 통해 시스템 명령어의 실행을 유도하여 권한을 탈취하거나 시스템 장애를 유발|
|위험한 형식 파일 업로드|악의적인 명령어가 포함된 스크립트 파일을 업로드하여 시스템 손상 또는 시스템 제어|
|신뢰되지 않는 URL 주소로 자동 접속 연결|입력 값으로 사이트 주소를 받는 경우 이를 조작하여 방문자를 피싱 사이트로 유도|
|메모리 버퍼 오버플로|연속된 메모리 공간을 사용하는 프로그램에서 메모리 범위를 넘어선 위치에 자료를 쓰거나 읽으려 할 때 발생|

### 111. 보안 기능
#### [1] 보안 기능
- 보안 기능의 보안 약점

|보안 약점|설명|
|:---:|:---:|
|적절한 인증 없이 중요기능 허용|보안검사를 우회하여 인증과정 없이 중요한 정보 또는 기능에 접근 및 변경|
|부적절한 인가|접근제어 기능이 없는 실행경로를 통해 정보 또는 권한을 탈취|
|중요한 자원에 대한 잘못된 권한 설정|권한 설정이 잘못된 자원에 접근하여 해당 자원을 임의로 사용|
|취약한 암호화 알고리즘 사용|암호화된 환경설정 파일을 해독하여 비밀번호 등의 중요정보를 탈취|
|중요정보 평문 저장 및 전송|암호화되지 않은 평문 데이터를 탈취하여 중요한 정보를 획득|
|하드코드된 암호화 키|암호화 키가 하드코딩된 경우 유출 시 역계산 또는 Brute Force 공격으로 탈취될 수 있음|

#### [1] 코드 오류

|:---:|:---:|

#### [2] 스택 가드(Stack Guard)

<br>

### 113. 캡슐화
#### [1] 캡슐화
- 캡슐화의 보안 약점

|보안 약점|설명|
|:---:|:---:|
|잘못된 세션에 의한 정보 노출|다중 스레드(Multi-Thread) 환경에서 멤버 변수에 정보를 저장할 때 발생|
|제거되지 않고 남은 디버그 코드|버그 수정이나 결과값 확인을 위해 남겨둔 코드들로 인해 발생|
|시스테 데이터 정보 노출|시스템의 내부 정보를 시스템 메시지 등을 통해 외부로 출력하여 발생|
|`Public` 메소드로부터 반환된 `Private` 배열|선언된 클래스 내에서만 접근이 가능한 `Private` 배열을 `Public` 메소드에서 반환하여 발생|
|`Private` 배열에 `Public` 데이터 할당|`Private` 배열에 `Public` 으로 선언된 데이터 또는 파라미터를 저장하여 발생|

### 114. 암호 알고리즘
#### [1] 암호 알고리즘
- **암호 알고리즘** : **중요 정보를 보호하기 위해 암호화된 문장으로 만드는 절차 또는 방법**

<br>

#### [2] 개인키 암호화(Private Key Encryption) 기법
- **개인키 암호화 기법** : **동일한 키로 데이터를 암호화하고 복호화**
  - 대칭 암호 기법 또는 단일키 암호 기법이라고도 함
  - 암호화/복호화 속도가 빠르지만, 관리해야 할 키의 수가 많다.

- 개인키 암호화 기법의 종류
  - **스트림 암호화 방식** : 평문과 동일한 길이의 스트림을 생성하여 비트 단위로 암호화(e.g., LFSR, RC4, TKIP)

  - **블록 암호화 방식** : 한 번에 하나의 데이터 블록을 암호화(e.g., DES, SEED, AES, ARIA, IDEA, Skipjack)

<br>

#### [3] 공개키 암호화(Public Key Encryption) 기법
- **공개키 암호화 기법** : **암호화할 때 사용하는 공개키(Public Key)는 공개하고, 비밀키(Secret Key, Private Key)는 관리자가 비밀리에 관리**
  - 비대칭 암호 기법이라고도 함
  - 관리해야 할 키의 수가 적지만, 암호화/복호화 속도가 느리다.
  - 대표적으로 RSA와 ECC 기법이 있다.

<br>

#### [4] 양방향 알고리즘의 종류

|알고리즘|특징|
|:---:|:---:|
|SEED|1999년 한국인터넷진흥원(KISA)에서 개발한 블록 암호화 알고리즘|
|ARIA(Advanced Research Institute Standard)|2004년 국가정보원과 산학연협회과 개발한 블록 암호화 알고리즘|
|DES(Data Encryption Standard)|1975년 미국 NBS에서 발표한 개인키 암호화 알고리즘|
|AES(Advanced Encryption Standard)|2001년 미국 표준 기술 연구소(NIST)에서 발표한, DES의 후속 개인키 암호화 알고리즘|
|RSA(Rivest-Shamir-Adleman)|1978년 MIT의 라이베스트, 샤미르, 아들만에 의해 제안된 공개키 암호화 알고리즘<br>큰 숫자를 소인수분해하기 어렵다는 것에 기반하여 만들어짐|
|ECC(Elliptic Curve Cryptography)|1985년 RSA 암호 방식의 대안으로 제안된 공개키 암호화 알고리즘<br>이산대수 문제를 타원곡선으로 옮긴 암호화 알고리즘|
|IDEA(International Data Encryption Algorithm)|1990년에 스위스의 라이와 메시가 개발한 PES의 후속 알고리즘|
|Skipjack|국가 안전 보장국(NSA)에서 개발한 암호화 알고리즘으로, 클리퍼 칩(Clipper Chip)이라는 IC 칩에 내장되어 있음|
|TKIP(Temporal Key Integrity Protocol)|무선랜 보안에 사용된 WEP을 보완한 데이터 보안 프로토콜|

<br>

#### [5] 해시(Hash)
- **해시** : **임의의 길이의 입력 데이터나 메시지를 고정된 길이의 값이나 키로 변환하는 것**

- 해시 함수의 종류

|해시 함수|특징|
|:---:|:---:|
|SHA 시리즈|1993년 미국 국가안보국(NSA)이 설계, 미국 국립표준기술연구소(NIST)에 의해 발표됨|
|MD5(Message Digest algorithm 5)|1991년 로널드 라이베스트가 MD4를 대체하기 위해 고안한 암호화 해시 함수|
|N-NASH|1989년 일본의 전신전화주식회사(NTT)에서 발표한 암호화 해시 함수|
|SNEFRU|1990년 R.C.Merkle가 발표한 해시 함수|

<br>

### 115. 서비스 공격 유형
#### [1] 서비스 거부(DoS; Denial of Service) 공격
- **서비스 거부 공격** : **대량의 데이터를 한 곳의 서버에 집중적으로 전송함으로써 서버의 정상적인 기능을 방해하는 것**

- 주요 서비스 거부 공격의 유형
  - Ping of Death
  - SMURFING
  - SYN Flooding
  - TearDrop
  - LAND Attack
  - DDoS(Distributed Denial of Service)

<br>

#### [2] Ping of Death
- **Ping of Death** : **패킷의 크기를 인터넷 프로토콜(IP) 허용 범위 이상으로 전송하여 네트워크를 마비시키는 서비스 거부 공격 방법**

<br>

#### [3] SMURFING
- **SMURFING** : **IP나 ICMP의 브로드캐스트 주소 특성을 악용하여 엄청난 양의 데이터를 한 사이트의 집중적으로 보냄으로써 네트워크를 불능 상태로 만드는 공격 방법**

<br>

#### [4] SYN Flooding
- **SYN Flooding** : **3-way-handshake 과정을 의도적으로 중단시킴으로써 서버가 대기 상태에 놓여 정상적인 서비스를 수행하지 못하게 하는 공격 방법**

<br>

#### [5] TearDrop
- **TearDrop** : **IP 패킷의 Fragment Offset 값을 변경시켜 패킷을 재조립할 때 오류로 인한 과부하를 발행시킴으로써 시스템이 다운되도록 하는 공격 방법**

<br>

#### [6] LAND Attack(Local Area Network Denial Attack)
- **LAND Attack** : **패킷을 전송할 때 송신 IP 주소와 수신 IP 주소를 모두 대상의 IP 주소로 하여 자신에 대해 무한하게 응답하게 하는 공격**

<br>

#### [7] DDoS(Distributed Denial of Service, 분산 서비스 거부) 공격
- **DDoS 공격** : **여러 곳에 분산된 공격 지점에서 한 곳의 서버에 대해 서비스 거부 공격을 수행하는 것**

- 분산 서비스 공격용 툴에는 Trin00, TFN, TFN2K, Stacheldraht 등이 있다.

<br>

#### [8] 네트워크 침해 공격 관련 용어

|용어|의미|
|:---:|:---:|
|세션 하이재킹(Session Hijacking)|서버와 클라이언트 사이의 세션 정보를 가로채는 공격 기법<br>TCP 3-way-handshake 과정에 끼어드는 TCP 세선 하이재킹이 대표적|
|ARP 스푸핑(ARP Spoofing)|ARP의 취약점을 이용한 공격 기법으로, 자신의 물리적 주소(MAC)를 공격 대상의 것으로 변조하여 공격 대상으로 가는 패킷을 가로채거나 방해|
|스미싱(Smishing)|SMS를 이용해 사용자의 개인 신용 정보를 빼내는 수법|
|사회 공학(Social Engineering)|인간 상호 작용의 깊은 신뢰를 바탕으로 사람들을 속이는 공격 기법|
|다크 데이터(Dark Data)|특정 목적을 가지고 수집했으나 활용 없이 저장만 되어있는 대량의 데이터|
|타이포스쿼팅(Typosquatting)|도메인 이름(주소)을 잘못 입력하는 사용자의 실수를 이용한 URL 하이재킹|
|스피어 피싱(Spear Phishing)|특정 대상을 선정한 후 일반적인 이메일로 위장한 메일을 지속적으로 발송하여 클릭을 유도|
|APT(Advanced Persistent Threats)|특정 기업이나 조직 네트워크에 침투해 활동 거점을 마련한 뒤 보안을 무력화시키고 정보를 수집 후 외부로 빼돌리는 공격 기법|
|무작위 대입 공격(Brute Force Attack)|암호키를 찾아내기 위해 적용 가능한 모든 값을 대입|
|큐싱(Qshing)|QR코드를 통해 악성 앱의 다운로드를 유도|
|SQL 삽입(SQL Injection) 공격|웹 응용 프로그램에 SQL을 삽입하여 DB 유출 및 변조|
|크로스사이트 스크립팅(XSS)|웹 페이지에 악의적인 스크립트를 삽입하여 정보 탈취 및 비정상적인 기능 수행 유발|
|스니핑(Sniffing)|네트워크의 중간에서 남의 패킷 정보를 도청|

<br>

#### [9] 정보 보안 침해 공격 관련 용어

|용어|의미|
|:---:|:---:|
|워터링 홀(Watering Hole)|특정 집단이 자주 방문하는 웹사이트를 사전에 감염시키는 공격 기법|
|스케어웨어(Scareware)|바이러스에 감염되었다고 속이거나 보안 위험이 있다고 거짓 경고 메시지를 보내 불필요한 소프트웨어 구매를 유도|
|C&C 서버|해커가 원격지에서 감염된 좀비 PC에 명령을 내리기 위해 사용하는 서버|
|봇넷(Botnet)|C&C 서버에 의해 원격 조종되는 다수의 좀비 PC 네트워크|
|웜(Worm)|네트워크를 통해 연속적으로 자신을 복제하여 시스템의 부하를 높여 다운시키는 바이러스의 일종|
|제로 데이 공격(Zero Day Attack)|발견된 취약점의 존재가 공표되기 전에 해당 취약점을 통하여 이루어지는 보안 공격|
|키로거 공격(Key Logger Attack)|사용자의 키보드 움직임을 탐지해 중요한 정보를 탈취하는 공격 기법|
|랜섬웨어(Ransomware)|컴퓨터에 잠입해 내부 문서나 파일을 열지 못하게 한 후 돈을 요구하는 악성 프로그램|
|백도어(Back Door, Trap Door)|액세스 편의를 위해 시스템 보안을 제거하여 만들어놓은 비밀 통로|
|트로이 목마(Trojan Horse)|정상적인 기능을 하는 프로그램으로 위장하여 프로그램이 동작할 때 활성화|
|RootKit|불법적인 해킹에 사용되는 기능들을 제공하는 프로그램들의 모음|

### 116. 서버 인증
#### [1] 보안 서버
- **보안 서버** : **개인정보를 암호화하여 송·수신할 수 있는 기능을 갖춘 서버**

<br>

#### [2] 인증(Authentication)
- **인증** : **로그인을 요청한 사용자의 정보를 확인하고 접근 권한을 검증하는 보안 절차**

<br>

#### [3] 지식 기반 인증(Something You Know)
- **지식 기반 인증** : **사용자가 기억하고 있는 정보를 기반으로 인증을 수행하는 것**

- 지식 기반 인증 유형 : 고정된 패스워드, 패스 프레이즈, 아이핀(I-PIN) 등

<br>

#### [4] 소유 기반 인증(Something You Have)
- **소유 기반 인증** : **사용자가 소유하고 있는 것을 기반으로 인증을 수행하는 것**

- 소유 기반 인증 유형 : 신분정, 메모리 카드(토큰), 스마트 카드, OTP(One Time Password) 등

<br>

#### [5] 생체 기반 인증(Something You Are)
- **생체 기반 인증** : **사용자의 고유한 생체 정보를 기반으로 인증을 수행하는 것**

- 생체 기반 인증 유형 : 지문, 홍채/망막, 얼굴, 음성, 정맥 등

<br>

#### [6] 행위 기반 인증(Something You Do)
- **행위 기반 인증** : **사용자의 행동 정보를 이용해 인증 수행**

- 행위 기반 인증 유형 : 서명, 동작

<br>

#### [7] 위치 기반 인증(Somewhere You Are)
- **위치 기반 인증** : **인증을 시도하는 위치의 적절성 확인**

- 위치 기반 인증 유형 : 콜백, GPS나 IP 주소를 이용한 위치 기반 인증

<br>
<br>

### 117. 보안 솔루션
#### [1] 보안 솔루션
- **보안 솔루션** : **외부로부터의 불법적인 침입을 막는 기술 및 시스템**

<br>

#### [2] 방화벽(Firewall)
- **방화벽** : **조직 내부의 네트워크와 인터넷 간에 전송되는 정보를 선별하여 수용·거부·수정하는 기능을 가진 침입 차단 시스템**

<br>

#### [3] 침입 탐지 시스템(IDS; Intrusion Detection System)
- **침입 탐지 시스템** : **컴퓨터 시스템의 비정상적인 사용, 오용, 남용 등을 실시간으로 탐지하는 시스템**

<br>

- 오용 탐지(Misuse Detection) : 미리 입력해둔 알려진 공격패턴을 감지
- 이상 탐지(Anomaly Detection) : 평균적인 시스템의 상태를 기준으로 비정상적인 행위나 자원의 사용을 감지

<br>

#### [4] 침입 방지 시스템(IPS; Intrusion Prevention System)
- **침입 방지 시스템** : **비정상적인 트래픽을 능동적으로 차단하고 격리하는 보안 솔루션**

<br>

#### [5] 데이터 유출 방지(DLP; Data Leakage/Loss Prevention)
- **데이터 유출 방지** : **내부 정보의 외부 유출을 방지하는 보안 솔루션**

<br>

#### [6] 웹 방화벽(Web Firewall)
- **웹 방화벽** : **웹 기반 공격을 방어할 목적으로 만들어진 웹 서버에 특화된 방화벽**

<br>

#### [7] VPN(Virtual Private Network, 가상 사설 통신망)
- **VPN** : **공중 네트워크와 암호화 기술을 이용하여 사용자가 마치 자신의 전용 회선을 사용하는 것처럼 해주는 보안 솔루션**

<br>

#### [8] NAC(Network Access Control)
- **NAC** : **네트워크에 접속하는 내부 PC의 MAC 주소를 IP 관리 시스템에 등록한 후 일관된 보안 관리 기능을 제공하는 보안 솔루션**

<br>

#### [9] SIEM(Security Information and Event Management)
- **SIEM** : **로그 및 보안 이벤트를 통합하여 관리하는 빅데이터 기반의 보안 솔루션**

<br>

#### [10] SSH(Secure Shell)
- **SSH** : **원격 서버에 접속할 때 사용하는 암호화된 통신 프로토콜**

<br>

#### [11] 템퍼 프루핑(Temper Proofing)
- **템퍼 프루핑** : **위·변조가 발생할 경우 소프트웨어를 오작동하게 만들어 악용을 방지하는 기술**

<br>

#### [12] OAuth(Open Authorization, 공개 인증)
- **OAuth** : **인터넷 애플리케이션에서 사용자 인증에 사용되는 표준 인증 방법으로, OpenAPI로 구현됨**
