# 정보처리기사
## 프로그래밍 언어 활용
### 118. 데이터 입·출력
- **헝가리안 표기법** : **변수명 작성 시 변수의 자료형을 알 수 있도록 자료형을 의미하는 문자를 포함하여 작성하는 방법
  - e.g., `i_InputA`, `d_Result`, `str_Name`, `b_Flag` 등

<br>

- C에서 숫자 앞에 `0`을 붙이면 8진수, `0x`를 붙이면 16진수로 인식함
  - e.g., `int i = 010;` → 8진수 `10` → 10진수 `8`  

<br>

- 연산자 우선순위
  - (1) 단항 연산자 `!`, `~`, `++`, `--`, `sizeof`
  - (2) 산술 연산자 `*`, `/`, `%`
  - (3) 시프트 연산자 `<<`, `>>`
  - (4) 관계 연산자 `<`, `<=`, `>`, `>=`, `==`, `!=`
  - (5) 비트 연산자 `&`, `^`, `|`  (`&`가 우선순위가 가장 높음)
  - (6) 논리 연산자 `&&`, `||`  (`&&`가 우선순위가 높음)
  - (7) 조건 연산자 `? :`
  - (8) 대입 연산자 `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `<<=`, `>>=`
  - (9) 순서 연산자 `,`

### 121. 구조체
- 구조체 일반 변수는 `.` 연산자로 멤버 접근

```c
struct sawon a;

a.name = "김성현";
```

- 구조체 포인터 변수는 `->` 연산자로 멤버 접근

```c
struct sawon *b;

b->name = "김성현";
// 또는
(*b).name = "김성현";
```

### 127. 예외 처리
- JAVA 예외 처리의 기본 형식

```java
try {
  // 예외가 발생할 가능성이 있는 코드;
}
catch (NullPointerException e1) {  // NullPointerException은 예시
  // 예외 발생 시 처리할 코드;
}
catch (Exception e2) {  // 아무 예외나 처리 가능한 Exception
  // 예외 발생 시 처리할 코드;
}
finally {
  // 예외 발생 여부와 상관없이 항상 실행되는 코드;
}
```
